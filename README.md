# beingamanforever.io

Personal site. Static HTML, regenerated by a small shell script.

## Run locally

```sh
python3 -m http.server 3456
# open http://localhost:3456
```

## Build

```sh
./scripts/build.sh
```

Builds every page from its template, renders all posts via Pandoc,
and regenerates `sitemap.xml` and `feed.xml` from post metadata.

## Layout

```
.
├── _partials/              shared HTML (nav, footer, head)
├── assets/                 css, js, og image, resume pdf
├── content/posts/          post sources (Markdown + YAML-style metadata)
├── data/projects.json      project list (single source of truth)
├── posts/                  rendered post HTML  (generated)
├── scripts/
│   ├── build.sh            builds the whole site
│   └── new-post.sh         scaffolds a new post Markdown file
├── *_template.html         page templates with <!-- MARKER --> placeholders
├── index.html              page output  (generated)
├── work.html               page output  (generated)
├── contact.html            page output  (generated)
├── blog.html               page output  (generated)
├── 404.html                page output  (generated)
├── sitemap.xml             generated
└── feed.xml                generated
```

Edit templates, partials, post Markdown, or `data/projects.json` —
never the generated files. See [BLOGGING.md](BLOGGING.md) for the
post workflow.

## Stack

Pandoc for Markdown → HTML. Bash + awk for templating. Plain CSS
(no preprocessor). Prism.js for syntax highlighting. No bundler,
no framework.

## Add a project

Edit `data/projects.json` and rerun `./scripts/build.sh`. Featured
projects (`"featured": true`) appear on the home page; all of them
appear on `work.html`.
